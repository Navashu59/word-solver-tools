# Content Guidelines

## Core Rule

SERP/PAA decides what the page must cover. User context decides how each answer is written.

## Writing Standard

- Start from the user's immediate situation.
- Keep answers concrete and short.
- Use examples, inputs, outputs, and filters.
- Do not write filler for length.
- Do not open tool pages with long definitions.
- Do not copy competitor wording or heading structures verbatim.
- Avoid generic AI phrasing like "in today's fast-paced world" or "this powerful tool helps users".
- Explain edge cases only when they affect the user's result.

## Page Order

1. H1 and one-line value statement.
2. Tool input.
3. Results.
4. Practical how-to section.
5. Examples.
6. Rule/dictionary notes where relevant.
7. FAQ based on PAA.
8. Internal links to adjacent tools.

## DeepSeek Use

Use DeepSeek for drafts, not final unchecked copy. Each content brief includes a DeepSeek prompt. After generation, edit for:

- specificity
- natural phrasing
- no padding
- no repeated boilerplate
- clear user action
- correct tool behavior
