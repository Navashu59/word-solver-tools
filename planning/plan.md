# Full Launch Plan

## Goal

Build a mature first-launch website around `word unscrambler`, not a thin MVP.

The site should establish authority in letter-based word solving tools by launching with:

- core tools
- game-specific solver pages
- puzzle-specific solver pages
- support guides
- FAQ/rules pages
- internal links between related intent clusters

## Key Adjustment

Every planned page keyword must receive its own SERP/PAA content framework.

This includes:

- Google top 3 result structure
- featured snippet or AI/widget notes when present
- People Also Ask questions
- related searches
- missing modules or better user-facing explanations
- page-specific user problem
- first-screen tool requirement
- original answer angle

Core pages get deeper analysis first, but support pages are not exempt.

## Content Principle

SERP/PAA decides what questions the page must cover.

User context decides how the answer should be written.

The content should:

- answer the user's immediate problem
- avoid generic filler
- avoid writing long sections only to increase word count
- use examples, inputs, outputs, filters, and next steps where useful
- keep the tool above the fold
- explain results in natural language
- be edited for low AI feel
- use DeepSeek for drafts when helpful, then revise against this standard

## Next Work Sequence

1. Create the full launch brief.
2. Build the complete page map.
3. For every page in the map, create a SERP/PAA framework file.
4. Convert SERP/PAA frameworks into page briefs.
5. Write or generate page copy using DeepSeek-assisted prompts.
6. Define the solver engine spec.
7. Check brand/legal risk for game-specific pages.
8. Only then move into implementation.
