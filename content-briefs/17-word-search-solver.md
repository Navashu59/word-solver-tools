# Content Brief - Word Search Solver

## Target

- Primary keyword: word search solver
- URL: /word-search-solver/
- Cluster: word-search
- Search volume: 18,100 US/month

## User Need

The user cannot find words in a letter grid and wants the hidden path highlighted.

## Above-The-Fold Requirement

The page must show the working tool before long explanatory content. Required controls:

- grid input
- target word list
- all direction search
- path highlight
- print/share solved grid

## Recommended Content Structure

1. H1 matching the primary action.
2. One short sentence that says what the tool does.
3. Tool input area.
4. Results area with filters.
5. Short "How to use it" section with an example.
6. Rules or dictionary notes when relevant.
7. FAQ answers from SERP/PAA.
8. Links to adjacent tools.

## Questions To Answer

- How do I solve a word search?
- Can words go diagonally or backwards?
- How do I enter a word search grid?
- Can I find multiple words at once?
- How do I highlight the hidden word path?

## Writing Rules

- Start with the exact situation the user is in, not a generic definition.
- Keep the first explanatory paragraph under 70 words.
- Use concrete input examples and explain the output.
- Avoid saying the tool is powerful/comprehensive unless the sentence explains how.
- Do not copy headings or wording from competitor pages; translate the need into our own workflow language.
- If the keyword is brand/game-specific, use descriptive wording and add a neutral trademark/disclaimer note.
