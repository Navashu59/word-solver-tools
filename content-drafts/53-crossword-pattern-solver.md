# Crossword Pattern Solver

Use this crossword pattern solver when the grid gives you fixed letters and blanks. It is pattern-first: enter the answer shape, then use the clue and crossings to choose from the candidates.

## Put the grid pattern into the solver

Write the answer as letters and ? marks. `??e?t` means five letters with e in position three and t at the end. If you know only the length, use five question marks for a five-letter slot, then add contains or starts with filters.

## Pattern versus clue search

Use this page when the grid pattern is the strongest evidence. Use the main [Crossword Solver](/crossword-solver/) when the clue wording is the main evidence. In practice, good crossword solving uses both: pattern first, clue meaning second.

## Check crossword-specific signals

- Abbreviated clues often need abbreviated answers.
- Plural clues usually need plural answers.
- Past-tense clues usually need past-tense answers.
- Theme answers may bend normal phrasing.
- Crossing letters beat a candidate that only vaguely fits the clue.

## Common Questions

### Do I need to enter the clue?

No. This page is designed for pattern-first solving. Add clue context mentally when choosing from the candidate list.

### What should I do when there are too many matches?

Add another known crossing letter, a starts-with filter, an ends-with filter, or an exclude filter from letters you know cannot fit.

### Can a pattern produce multiple valid answers?

Yes. Crosswords often have several words that fit the same pattern. The clue decides which one belongs in the grid.
