# Word Maker

You have a handful of letters and want to see what words you can build – not just the longest or highest-scoring, but all the possibilities. Word Maker is about creativity: it shows you every combination, from short common words to obscure finds you might have missed.

## Turn random letters into real words

Maybe you’re playing a word game, or maybe you’re just messing around with anagrams. Type your letters into the box, and the tool will generate every valid English word. It’s like having a dictionary that only contains words made from your letters.

## Use it for brainstorming and learning

Word Maker isn’t just for games. If you’re learning new vocabulary, enter a set of letters and see how many words you can recognize. Challenge yourself to find words you didn’t know existed. It’s a fun way to expand your word bank.

## Filter by word length to focus your search

If you only want 4-letter words or 6-letter words, set the length filter. This helps when you have a specific slot to fill in a crossword or a limited space on a game board.

## Advanced filters: starts with, ends with, contains

Narrow down results even further. For example, if you need a word that contains “X” or starts with “Z”, use the contains or starts-with filter. This is especially useful for games where certain letters are worth more points.

## Common Questions

### What words can I make with these letters?

Enter your letters in the input field. The tool will list all words that can be formed from those letters.

### Do I have to use every letter?

No. The tool shows words using any subset. Check “use all letters” if you want only words that use every letter.

### Can I use wildcards or blank tiles?

Yes. Use `?` or `.` for any single unknown letter.

### Can I filter by word length?

Yes. Set an exact length to control the results.

### Can I exclude letters from results?

Yes. Type letters to exclude, and words containing them will be removed.

## Quick checks before you use these results

A word maker should reduce the list without hiding the rules behind the result. Before you play, submit, or copy a word, check these points:

- **Letter use:** If the puzzle only needs a shorter word, allow subset results; if it must use every tile, match the length to your input and check the longest group first.
- **Wildcards:** Treat ? or blank tiles as flexible letters, then remove them if the game does not allow blanks.
- **Game rules:** For named word games, check the accepted dictionary or house rules before using a result as final.
- **Result sanity:** If a word looks unfamiliar, verify it before using it in a scored game or published puzzle answer.
