# Word Cheat

You’re in the middle of a word game - Scrabble, Words With Friends, or a crossword - and you need a word fast. This tool is built for speed: enter your letters, set a few constraints, and get a short list of playable words. No long explanations, no extra steps.

## Enter your rack, get options

Type your letters into the input. If you have a blank tile, use `?`. The tool will immediately show candidate words you can make. The results are sorted by length and score (if applicable), so the best options appear first.

## Add constraints only if needed

If you know the word must be a certain length, set it. If a letter is already on the board and you need to build off it, use the starts-with or ends-with filter. The fewer filters you add, the more results you’ll see - but adding one or two can turn a huge list into a handful of good choices.

## Use the exclude field to eliminate duds

If you’ve already tried some letters and they didn’t work, add them to the exclude field. The tool will remove any word containing those letters. This is a quick way to avoid repeating bad guesses.

## Check the word before you play

This tool uses a general English dictionary. Some games have their own game-specific word lists (like Scrabble’s TWL or WWF’s list). Before you commit, make sure the word is allowed in your specific game. The tool is a helper, not a referee.

## Common Questions

### What words can I make with these letters?

Enter your letters and click solve. The tool will return candidate words that can be formed from those letters, sorted by length and score.

### Do I have to use every letter?

No. By default, the tool finds words from any subset. If you want to use all letters, manually check whether a result uses every letter.

### Can I use wildcards or blank tiles?

Yes. Type `?` for each blank. The tool treats it as any letter.

### Can I filter by word length?

Yes. Set an exact length . This is the most effective filter for narrowing results.

### Can I exclude letters from results?

Yes. Type letters you want to exclude in the exclude field. Results containing those letters will be removed.
