This descrambler is built for anagramming: it rearranges your letters into all valid dictionary words, from short two-letter words to the longest possible. Use it when you need to find hidden words, solve anagrams, or expand your vocabulary.

Finding all anagrams of a word or phrase

Enter any word or phrase (letters only, no spaces). The descrambler returns every anagram - words that use exactly those letters. For example, entering “listen” gives you “silent,” “enlist,” and “tinsel.” This is perfect for word games where you need to rearrange tiles into a new word, or for puzzles that ask for anagrams.

Using the descrambler for word games like Scrabble

In Scrabble, you often have a rack of seven letters and need to find the best word. Enter your rack, and the descrambler shows all possible words, sorted by length or score. The longer the word, the more points. Use the score sort to see which word gives you the highest total. This tool is an unofficial helper - it doesn’t connect to any game server.

Filtering by word length for specific game needs

If you need a five-letter word for Wordle or a three-letter word for a crossword, set the length filter. The descrambler only shows words of that exact length. This saves you from scrolling through a long list when you know the word size.

Excluding letters you’ve already ruled out

When you know certain letters aren’t in the answer, type them into the exclude box. The descrambler removes any word containing those letters. This is useful when you’ve already tried some letters and want to focus on the remaining possibilities.

Copying words for quick use

Each result has a copy button. Click it to copy the word to your clipboard. No need to highlight or right-click. This makes it easy to paste the word into a game, a message, or a document.

Common Questions

What words can I make with these letters?

Enter your letters into the input box. The descrambler returns every valid word that can be formed. Results are grouped by length, with the longest words first.

Do I have to use every letter?

No. The descrambler shows words that use any subset of your letters. If you want only words that use all letters, check the “use all letters” option.

Can I use wildcards or blank tiles?

Yes. Use a question mark (?) or a period (.) for each unknown letter. The descrambler will try every letter in that position.

Can I filter by word length?

Yes. Use the length field to set an exact length. Results update automatically.

Can I exclude letters from results?

Yes. Type letters to exclude in the exclude field. Any word containing those letters is removed.

Before you use the word list

Before you use a result, check the constraint that matters most for your puzzle: exact length, required letters, excluded letters, or whether every tile must be used. Tighten only one filter at a time so you can see which rule removed the right candidates.
